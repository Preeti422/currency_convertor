# Currency Converter 💱

A simple and responsive currency converter web application built using HTML, CSS and JavaScript.

## 🚀 Features

- Convert currencies in real time
- Currency selection with country flags
- Fetches exchange rates using an API
- Simple and user-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📌 Project

This project was created to practice JavaScript, API integration, DOM manipulation and responsive web design.
